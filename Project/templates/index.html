Key Research Highlights

AdaBoost achieved the highest accuracy (80.50%) across a 10-model pipeline trained on 9,994 customer records. The dataset exhibited a 47:53 churn class imbalance. SMOTE oversampling was applied on the training fold only to prevent data leakage during cross-validation proceedings.

Pipeline included: Z-score outlier capping at ±3σ, StandardScaler normalization, One-Hot Encoding for Gender and DeviceUsed, Binary mapping for HasPremiumMembership, and Pearson correlation + VIF-based multicollinearity analysis reducing features from 17 to 14.

Model Convergence Insights

Academic Research Summary

Methodology, data science findings, and statistical analysis for the e-commerce customer churn prediction study.

Abstract
AdaBoost SMOTE PCA
This study investigates predictive modeling strategies for identifying customer churn in e-commerce environments. Using a dataset of 9,994 customer records with 17 initial behavioral and demographic features, we benchmark 10 machine learning classifiers under a rigorous 5-fold stratified cross-validation framework. The AdaBoost Classifier, configured with 200 base estimators and a learning rate of 0.50, emerged as the champion model achieving 80.50% classification accuracy and a 59.21% macro-averaged F1-Score. The pipeline incorporates SMOTE oversampling, StandardScaler normalization, and PCA-based dimensionality reduction to produce a robust, generalizable predictive system suitable for production deployment.
Data Cleansing & Pre-processing
Pipeline
The raw dataset underwent a multi-stage cleansing pipeline prior to model training. Missing values were handled using median imputation for continuous variables and mode imputation for categorical features. Outlier detection employed the Z-score method with a ±3σ threshold — extreme values were capped rather than dropped to preserve sample size integrity.
Categorical encoding: Gender and DeviceUsed were One-Hot Encoded; HasPremiumMembership was mapped to binary {0,1}. Continuous features were normalized with StandardScaler (μ=0, σ=1). SMOTE was applied exclusively within each training fold to prevent information leakage from the validation partition.
Addressing the Curse of Dimensionality
VIF + PCA
The initial feature space of 17 dimensions was assessed using two complementary techniques. Pearson correlation analysis identified three feature pairs with |r|>0.85, eliminating one redundant variable per pair. Variance Inflation Factor (VIF) analysis confirmed no severe multicollinearity in the refined 14-feature set (all VIF scores below 5.0).
PCA was applied during model selection experiments with a 95% explained variance threshold, retaining 11 principal components. The final deployment pipeline uses the interpretable 14-feature model for stakeholder transparency.

Methodology
5-Fold CV
The experimental framework followed a structured ML pipeline: (1) Exploratory Data Analysis with statistical profiling, (2) data cleansing and feature engineering, (3) stratified 80/20 train/test split, (4) 5-fold cross-validation with per-fold SMOTE, (5) GridSearchCV hyperparameter tuning for top-3 candidate models, and (6) final evaluation on the held-out test set across accuracy, precision, recall, F1-score, and ROC-AUC.
The champion AdaBoost model was serialized using Joblib and integrated into a Flask REST backend exposing a /predict POST endpoint. Raw inputs are preprocessed through the saved scaler pipeline before inference.
